A high-performance, premium personal portfolio built with **Next.js 15 (Turbopack)**, featuring a cybersecurity-inspired aesthetic, real-time AI interactions, and mission-critical UI components.

---

### ✨ Premium Features

- **🛡️ Cybersecurity HUD Interface:** A deep-space dark theme with neon cyan and violet accents, designed for clarity and impact.
- **📟 High-Contrast Matrix Engine:** Custom-built Canvas API background with optimized performance, throttling, and a "glowing head" effect for maximum legibility.
- **🤖 Intelligence Core (AI Chatbot):** Integrated with **Llama 3.3 via Groq AI**, providing instant, intelligent responses about my professional profile and research.
- **📡 Smart Contact HUD:** A defensive-designed contact system that offers multiple protocols (Direct Web Gmail, Mailto, or Clipboard Copy) ensuring 100% reachability across all devices.
- **📱 Universal Responsiveness:** Audited for perfect display on iPhone (Safari WebKit), Android, Linux, and Desktop browsers.
- **⚡ Performance Optimized:** Throttled event listeners, hardware-accelerated animations, and zero-error TypeScript build.

---

### 🛠️ Architecture & Stack

- **Framework:** Next.js 15 (App Router)
- **Styling:** Tailwind CSS + Framer Motion (Animations)
- **Database/Auth:** Supabase
- **AI Engine:** Groq SDK (Llama 3.3 Model)
- **Type Safety:** 100% TypeScript Coverage
- **Icons:** Lucide React + Custom SVG Brand Assets

### 🚀 Getting Started

1. **Clone the mission:**
   ```bash
   git clone https://github.com/marlonperez70/Ing-Marlon-P-rez.git
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure the Neural Link (.env.local):**
   ```env
   NEXT_PUBLIC_SUPABASE_URL=your_url
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your_key
   GROQ_API_KEY=your_key
   ```

4. **Launch Deployment:**
   ```bash
   npm run dev
   ```
